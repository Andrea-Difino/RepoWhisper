Quick Start

RepoWhisper is currently designed for Python code analysis. Source retrieval and static analysis are Python-oriented, and other languages are not yet supported as analysis targets.

The facade accepts a source target, an initialized LangChain chat model, and an optional explanation level.

from langchain_groq import ChatGroq
from repowhisper import RepoWhisper, UserLevel, RepoWhisperError

llm = ChatGroq(
    api_key="read this from an environment variable",
    model="openai/gpt-oss-120b",
    max_tokens=6000,
)

engine = RepoWhisper(
    source_target="repo_url",
    llm=llm,
    user_level=UserLevel.JUNIOR,
)

try:
    json_data = engine.generate_documentation()
except RepoWhisperError as e:
    print(f"RepoWhisper failed: {e}")

generate_documentation() returns a JSON string when analysis succeeds and None when the run is interrupted or cannot produce a result.

The configured LLM generates the Architect, Navigator, and Storyteller output. The module review step uses the local Laya/Vega classifier and does not consume LLM tokens.

To generate the documentation and open the bundled interface in a browser:

engine.analyze()

For an application entry point, wrap the call in try/except to handle provider, repository, and server errors without an unhandled traceback:

try:
    engine.analyze()
except RepoWhisperError as e:
    print(f"RepoWhisper failed: {e}")

RepoWhisper handles user interruptions internally. Other errors are raised to the caller so that applications can log them or present an appropriate message.

The default server port is 8543. Pass a different port when needed:

engine.analyze(port=9000)

Place this code in your application entry point. If the entry point is a module inside the repowhisper package, run it from the repository root in module mode (for example, python -m repowhisper.<module>), rather than running its file directly from inside the package directory.

Explanation levels

UserLevel changes the amount and style of explanation produced by the Navigator and Storyteller agents:

  • UserLevel.JUNIOR provides detailed, educational explanations.
  • UserLevel.MID focuses on integration, contracts, and state transitions.
  • UserLevel.SENIOR emphasizes trade-offs, performance, and extension points.
