Output Format

generate_documentation() returns a JSON string. Parse it before consuming the result:

import json

data = json.loads(engine.generate_documentation() or "{}")

The top-level structure is:

{
  "title": "RepoWhisper Analysis",
  "tree_structure": "...",
  "narrative": "...",
  "raw_modules": []
}

Top-level fields

title

Constant title for the generated analysis.

tree_structure

Textual tree of the analyzed repository, excluding ignored directories.

narrative

The final architectural narrative generated by the Storyteller agent.

raw_modules

List of per-file analysis objects:

{
  "file": "src/example.py",
  "explanation": "The module ...",
  "code_snippet": "class Example: ...",
  "notes": {
    "11": "Creates the service dependency."
  }
}

file is the repository-relative path. explanation is the Navigator output, code_snippet contains the analyzed source, and notes maps zero-based line indexes to line-level insights for the UI.

Failure behavior

The facade returns None when the user interrupts the run. It raises an error when no parsable source is found or when a required processing step fails. Applications should distinguish an empty JSON result from an interrupted or failed analysis.
