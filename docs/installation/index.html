Installation

Requirements

  • Python 3.12.
  • Git, when analyzing a remote repository.
  • An LLM provider supported by LangChain.
  • Network access and cache space for the first-run Laya/Vega reviewer download.

Install from PyPI

For the standard installation, install the published package from PyPI:

python -m pip install repowhisper

The base package includes RepoWhisper and its core dependencies. To install RepoWhisper together with the integration for a specific LLM provider, use the corresponding optional dependency:

python -m pip install "repowhisper[groq]"
python -m pip install "repowhisper[ollama]"
python -m pip install "repowhisper[openai]"
python -m pip install "repowhisper[anthropic]"

Each provider extra includes the base RepoWhisper installation and the provider-specific LangChain integration.

Install from the repository

For development, or to work with the source code, clone the repository and install the project from its root:

uv sync

Alternatively, install the local package with pip:

python -m pip install .

Optional LLM integrations can also be installed from the local checkout:

python -m pip install ".[groq]"
python -m pip install ".[ollama]"
python -m pip install ".[openai]"
python -m pip install ".[anthropic]"

Install documentation dependencies

The development dependency group includes MkDocs and mkdocstrings:

uv sync --group dev

Build the documentation with:

.\.venv\Scripts\mkdocs.exe build --strict

Preview it locally with:

.\.venv\Scripts\mkdocs.exe serve

Credentials

Do not commit credentials. Store provider keys in environment variables or a local .env file, which is ignored by Git.
