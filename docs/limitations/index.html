Limitations and Troubleshooting

Current limitations

  • RepoWhisper currently supports Python code analysis only. It is not a general-purpose analyzer for JavaScript, TypeScript, Java, Go, Rust, or other languages.
  • The dependency tracer currently analyzes Python imports and final file processing excludes __init__.py, test directories, virtual environments, build output, and source-control directories.
  • The quality of generated explanations depends on the selected LLM.
  • The grounding verifier detects invented names (files, classes, functions, libraries, flags), not incorrect descriptions of behaviour.
  • Static facts (symbols, imports, entry points) are extracted from Python only.
  • The local Laya Reviewer requires an initial model download and Hugging Face cache space.
  • Large repositories can require substantial time, memory, and model tokens.
  • The bundled HTTP server is intended for local use, not production hosting.
  • analyze() writes generated source data into the bundled UI directory.

Common issues

No parsable code found

Confirm that the target contains .py files and that the path or Git URL is correct.

Git clone failure

Check that Git is installed and that credentials are available for private repositories.

Missing provider package

Install the matching optional extra, for example:

uv sync --extra groq

Missing provider key

Set the provider key in the environment before creating the chat model. Never hard-code or commit the key.

Documentation import errors

Run MkDocs from the repository root and use the project environment:

.\.venv\Scripts\mkdocs.exe build --strict
