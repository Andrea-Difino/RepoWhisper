MODEL.PY

The Model class declares a contract for language-model backends that surface sensitive indices in tokenized text. By inheriting from ABC and marking run_model with @abstractmethod, the framework guarantees that each concrete implementation supplies the core inference routine while allowing callers to treat all models polymorphically. The signature chunk: dict[int, str] expects a zero-based index map of tokens, and ambiguous_idx: list[int] | None gives the extractor a chance to hand off uncertain positions; a None value simply skips the secondary pass. Returning dict[int, str] ties each flagged index to an entity label. This design balances type safety with flexibility but relies on Python 3.9+ dict-type annotations and assumes token indices are contiguous, which may not hold for sub-word tokenizers.
